
# Overview

As a software engineer, I am working to strengthen my understanding of basic C++ programming and the process of building and running code from a development environment.

This software is a simple Hello World program written in C++. When the program runs, it displays the message `Hello World` in the terminal.

My purpose for creating this software is to practice setting up a C++ project, writing a basic program, compiling the code, fixing build issues, and running the finished program successfully.

[Software Demo Video](https://youtu.be/BC1YFZY8TXQ)

# Development Environment

I used Visual Studio Code to write and edit the program. I also used the VS Code integrated terminal to build and run the software. The program was developed on macOS using the Clang C++ compiler.

The programming language I used was C++. The program uses the `<iostream>` library and `std::cout` to print output to the terminal.
